# Exemplo original: ManyWormsKilled — C# nativo

O exemplo traduz o arquivo \`samples/ExampleMod/content/Content/Achievements/ManyWormsKilled.js\` do ExampleModBunny 1.9.0.

Mantém a categoria Collector, a ocultação até a primeira morte, a contagem numérica de cinco e a validação do jogador local. O ID vanilla GiantWormHead = 10 foi conferido com a tabela de IDs do Terraria. A textura PNG é o blob original de 4303 bytes do mesmo repositório, sem recompressão, redimensionamento ou conversão.

Este pacote é um fixture compilável separado; não altera os 100 fontes do ExampleMod principal na PR #141. O carregamento em menu, os ícones, as notificações e o salvamento persistente continuam aguardando QA da ponte nativa Android. Não gerar APK nem anunciar paridade final.
